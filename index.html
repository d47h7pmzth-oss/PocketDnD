The Twin-App Ecosystem

Pocket D&D features data-carrying QR generations that bypass the requirement for live server connectivity. When the DM creates custom loot or triggers environmental items inside Pocket DM, a local QR code is rendered instantly on-screen.

Players scan the code with Pocket Player to add the item directly into their sheet database, instantly updating background stat structures. No server linking, no table clutter, no broken immersion.
